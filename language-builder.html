Pembuat bahasa

Tambahkan bahasa baru ke language.json. Teks Indonesia diterjemahkan otomatis, kamu periksa dan perbaiki, lalu unduh atau salin file lengkapnya. Bahasa baru selalu ditambahkan di bawah bahasa yang sudah ada.

1Buka language.json

Dimuat otomatis dari language.json di folder yang sama. Kalau gagal (mis. dibuka dari file lokal), pilih file atau tempel isinya.

Tempel JSON

+Sinkronkan teks dari halaman HTML

Opsional. Pilih satu atau beberapa file .html. Teks yang tampil dibaca, lalu teks yang belum ada di language.json (bagian Indonesia) ditambahkan sebagai key baru. Kalau halaman belum memuat i18n.js, kamu bisa mengunduh HTML yang sudah disisipi scriptnya. Isi halaman selain itu tidak diubah. Hilangkan centang pada teks yang bukan bahasa Indonesia (mis. contoh kalimat English).

Muat language.json dulu (langkah 1), lalu pilih file HTML.

3Periksa dan perbaiki

Terjemahan bisa diedit langsung. Penanda seperti {n} dan tanda “…” mewakili nilai yang disisipkan program, jadi harus tetap ada di terjemahan.
