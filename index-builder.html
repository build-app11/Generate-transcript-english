Pembuat index.json

Pilih semua file JSON pelajaran sekaligus, lalu unduh index.json yang sudah diperbarui secara keseluruhan untuk daftar di index.html.

1Pilih file JSON

2Periksa daftar

    3Unduh index.json

    Lihat isi file
    Setelah itu
    1. Buka repositori di GitHub, folder data/.
    2. Upload index.json ini dan timpa yang lama. Pelajaran baru juga di-upload ke folder yang sama.
    3. Tunggu beberapa saat, lalu muat ulang index.html.

    Centang di daftar menentukan pelajaran mana yang masuk. Entri dari index lama yang filenya tidak dipilih tetap dipertahankan; hilangkan centangnya untuk menghapusnya dari daftar.
